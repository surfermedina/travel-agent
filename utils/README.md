# Utils

Helper modules for the Banking Agent.

- `logger.py` — centralized logging config
- `match_faq.py` — FAQ fuzzy matching with RapidFuzz
- `pdf_cleaner.py` — PDF text cleaning for ingestion
- `preprocess_input.py` — normalize/sanitize user input
- `rag_ingest.py` — script to ingest PDFs into Chroma
- `rag_retriever.py` — helper for RAG document retrieval
- `sanitize.py` — input sanitization helpers
- `yaml_loader.py` — safe YAML loader for prompts/FAQ
